# 🌀또또

SillyTavern에서 최근 AI 답변의 반복 문구, 비슷한 문장 구조, 반복되는 서술 반응과 캐릭터 대사를 찾아 다음 생성에서 잠시 피하도록 주입하는 UI 확장입니다.

## 주요 기능

- 서술과 대사를 분리해 분석
- 동일·유사 구절, 반복되는 문장 시작과 끝, 자주 반복되는 반응 구조 감지
- 캐릭터별 대사 분석: 같은 대사, 말끝, 질문 방식은 잡되 캐릭터 고유 말투는 더 엄격한 기준으로 보호
- 일반 생성, 재생성, 스와이프, 계속 생성에만 동적 금지 지침 주입
- quiet·impersonate 등 백그라운드 생성에는 주입하지 않음
- 선택적 AI 정밀 분석으로 단어가 달라도 의미가 같은 반복 습관 감지
- 현재 연결 또는 별도 Connection Profile 사용 가능
- 스와이프, 수정, 삭제, 채팅 전환 시 현재 채팅 기준으로 다시 계산
- 감지 항목별 허용 처리와 주입문 미리보기
- `<Info_panel>...</Info_panel>` 및 정규식으로 렌더링된 `.info-card` 전체를 감지·정밀 분석에서 제외

## 설치

저장소 URL을 SillyTavern의 `확장 → 확장 설치`에 입력합니다. 수동 설치 시 이 폴더를 `data/default-user/extensions/ttotto`에 놓고 SillyTavern을 새로고침합니다.

## 기본 동작

- 로컬 반복 감지는 기본으로 켜져 있으며 별도 API 호출이 없습니다.
- AI 정밀 분석은 기본으로 꺼져 있습니다. 켜면 설정한 간격마다 API 사용량이 발생합니다.
- 감지 결과는 다음 생성에만 프롬프트로 주입되며 기존 채팅, 작가노트, 프리셋, 캐릭터 카드 및 로어북을 수정하지 않습니다.
- 번역 확장이 원문을 메시지 메타데이터에 보존하면 `저장된 원문 우선` 모드가 알려진 원문 필드를 우선 사용하고, 찾지 못하면 현재 메시지를 분석합니다.

## 권장 설정

- 분석 범위: 최근 답변 20개
- 감지 민감도: 보통
- 서술 반복 검사: 켬
- 대사 반복 검사: 켬
- 한 번에 주입할 항목: 최대 6개
- AI 정밀 분석: 필요할 때만 켬

## 데이터와 안전

- API 키를 저장하지 않습니다.
- 로컬 감지는 브라우저 안에서 처리됩니다.
- 정밀 분석을 켠 경우 최근 AI 답변 일부가 선택한 SillyTavern 연결을 통해 분석 모델로 전송됩니다.
- 생성 직전 주입에 실패하더라도 본 채팅 생성은 중단하지 않습니다.
