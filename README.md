# 🌀또또

SillyTavern에서 최근 AI 답변의 반복 문구, 비슷한 문장 구조, 반복되는 서술 반응과 캐릭터 대사를 찾아 다음 생성에서 잠시 피하도록 주입하는 UI 확장입니다.

## v1.3.0 태그 블록 자동 제외

- `태그·HTML 블록 전부 제외`가 기본으로 켜져 있습니다.
- `<Info_panel>`, `<Info_block>`, `<Status_box>`처럼 이름이 달라져도 여는 태그와 닫는 태그 사이를 통째로 분석에서 제외합니다.
- 클래스 이름과 관계없이 `<div>...</div>`, `<section>...</section>`, `<table>...</table>` 같은 쌍 태그도 중첩 구조까지 제외합니다.
- 실제 본문 전체를 태그로 감싸는 프롬프트를 사용하는 경우에는 이 기능을 끄고 기존의 개별 태그·클래스 입력을 사용할 수 있습니다.

## v1.2.1 성능 수정

- 긴 채팅 전체를 매번 읽지 않고 설정한 최근 분석 범위만 역순으로 수집
- 채팅을 열 때 메시지마다 발생하는 렌더 이벤트의 반복 분석 제거
- 스트리밍·번역기의 연속 `MESSAGE_UPDATED` 이벤트를 한 번으로 합치고 화면 표시만 바뀐 경우 분석 생략
- UI 갱신과 생성 직전에는 캐시를 재사용하고, 최근 원문이 실제로 달라졌을 때만 반복 감지 재실행
- 또또 전체 또는 현재 채팅 사용이 꺼져 있으면 로컬 분석과 정밀 분석 예약을 실행하지 않음

## 주요 기능

- 서술과 대사를 분리해 분석
- 동일·유사 구절, 반복되는 문장 시작과 끝, 자주 반복되는 반응 구조 감지
- 카드의 아바타 키에 연결된 또또 전용 UUID로 캐릭터를 구분해, 같은 이름의 다른 카드끼리 감지·허용 기록을 섞지 않음
- 캐릭터별 대사 분석: 같은 대사, 말끝, 질문 방식은 잡되 캐릭터 고유 말투는 더 엄격한 기준으로 보호
- 일반 생성, 재생성, 스와이프, 계속 생성에만 동적 금지 지침 주입
- quiet·impersonate 등 백그라운드 생성에는 주입하지 않음
- 선택적 AI 정밀 분석으로 단어가 달라도 의미가 같은 반복 습관 감지
- 현재 연결 또는 별도 Connection Profile 사용 가능
- 스와이프, 수정, 삭제, 채팅 전환 시 현재 채팅 기준으로 다시 계산
- 감지 항목별 캐릭터 UUID 허용 처리와 주입문 미리보기
- `<Info_panel>...</Info_panel>` 및 정규식으로 렌더링된 `.info-card` 전체를 감지·정밀 분석에서 제외
- 분석 범위가 가득 찬 장기 채팅에서도 새 답변 수를 별도로 추적해 정밀 분석을 계속 갱신
- 수정·삭제·스와이프·채팅 전환 시 오래된 정밀 분석 결과를 폐기하고 안전하게 재계산
- 생성 완료·중단 및 확장 비활성화 시 임시 주입과 예약된 백그라운드 작업을 정리
- 허용한 패턴은 같은 캐릭터 카드의 다른 채팅에서도 유지되며, 이름이 같은 다른 카드에는 적용되지 않음
- 메시지 수신 직후 실리태번 원문을 별도 보존하고, 신뢰할 수 있는 원문이 없는 메시지는 번역문 대신 분석에서 제외
- 🪶번역기의 `display_text`는 읽지 않고 현재 스와이프 또는 `message.mes`의 실리태번 원문만 분석
- 기존 채팅, 스와이프, 실리 기본 메시지 편집에서도 현재 원문을 다시 확인해 오래된 원문이 남지 않도록 갱신
- 감지된 패턴을 캐릭터 UUID별로 영구 고정하거나, 원하는 단어·표현을 직접 영구 금지어로 등록
- 영구 금지어가 새 답변에 다시 등장하면 감지 목록 위에 경고 표시
- 감지 근거 예시를 펼쳐 보고 현재 채팅의 원본 메시지로 바로 이동
- 다음 생성 한 번만 주입을 쉬고 그다음 생성부터 자동 복귀
- 사용자가 지정한 태그와 HTML 클래스를 분석에서 추가 제외
- 선택적으로 같은 캐릭터 UUID의 지난 채팅 원문을 최대 50개 기억해 함께 분석

## 설치

저장소 URL을 SillyTavern의 `확장 → 확장 설치`에 입력합니다. 수동 설치 시 이 폴더를 `data/default-user/extensions/ttotto`에 놓고 SillyTavern을 새로고침합니다.

## 기본 동작

- 로컬 반복 감지는 기본으로 켜져 있으며 별도 API 호출이 없습니다.
- AI 정밀 분석은 기본으로 꺼져 있습니다. 켜면 설정한 간격마다 API 사용량이 발생합니다.
- 감지 결과는 다음 생성에만 프롬프트로 주입되며 기존 채팅, 작가노트, 프리셋, 캐릭터 카드 및 로어북을 수정하지 않습니다.
- 또또는 화면 표시용 번역문이 아니라 현재 스와이프 또는 `message.mes`에 저장된 실리태번 원문만 분석합니다. 🪶번역기가 사용하는 `extra.display_text`는 분석하지 않습니다.
- 직접 금지어는 AI가 생성하는 원문 언어로 등록하는 것이 가장 정확합니다. 영구 금지 지침은 매 생성에 강하게 넣지만, 생성 모델이 지시를 무시할 가능성까지 수학적으로 0%로 보장하지는 않습니다.

## 권장 설정

- 분석 범위: 최근 답변 20개
- 감지 민감도: 보통
- 서술 반복 검사: 켬
- 대사 반복 검사: 켬
- 한 번에 주입할 항목: 최대 6개
- AI 정밀 분석: 필요할 때만 켬
- 같은 캐릭터의 지난 채팅 기억: 여러 채팅에서 반복되는 버릇까지 잡고 싶을 때만 켬

## 데이터와 안전

- API 키를 저장하지 않습니다.
- 캐릭터 카드는 수정하지 않습니다. 카드의 아바타 키와 또또가 만든 UUID의 연결만 확장 설정에 저장합니다.
- 로컬 감지는 브라우저 안에서 처리됩니다.
- 지난 채팅 기억을 켜면 카드 UUID별 원문 답변을 확장 설정에 최대 50개까지 저장합니다. 같은 이름이어도 UUID가 다른 카드는 섞이지 않습니다.
- 정밀 분석을 켠 경우 최근 AI 답변 일부가 선택한 SillyTavern 연결을 통해 분석 모델로 전송됩니다.
- 생성 직전 주입에 실패하더라도 본 채팅 생성은 중단하지 않습니다.
